## `03` / FEATURED PROJECTS

### 01 — ContextIQ | AI Document Intelligence

> Ask questions about your documents. Retrieve relevant context. Generate grounded answers.

**ContextIQ** is a document question-answering application built
around Retrieval-Augmented Generation (RAG).

- Extracts text from uploaded PDF documents.
- Creates semantic embeddings using Sentence Transformers.
- Stores and retrieves relevant chunks with ChromaDB.
- Uses the Gemini API to generate context-aware responses.
- Provides a FastAPI backend for the application.

**Stack:** Python · FastAPI · ChromaDB · Sentence Transformers · Gemini API
